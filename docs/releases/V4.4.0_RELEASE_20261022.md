## 纳入范围

- Windows Access MDB 记录编辑、批量操作和撤销，保护自动编号、精确数值、系统/链接表及不可靠记录身份；保存前备份、独立回读并检查外部变更。需要本机可用的 Jet/ACE，组件不可用时只读，不直接编辑运行中的服务端数据库。
- GOM/GEE 的静态 DELAYGOTO 及已核 DELAYCALL 标签导航；不将尚未实现的其他回调命令宣传为已支持。
- MapInfo 连接行两端分别打开当前服务端的原始地图并定位坐标，保留未保存文本和地图就绪生命周期保护。
- 动态变量按程序点跟踪覆盖赋值、已核算术/公式、NPC 参数、列表和表格数据；修复先 ELSEACT 后 ACT 的控制流漏归属，同分支 ACT/SAY 连续处理，真假分支不串行运算。
- 变量来源区分直接、确定推导、可能与未解；计数为源码引用处数，不是运行次数。候选仅表示当前范围未发现引用，未知写入和超限保持不确定提示。
- README 按当前功能整理，明确保存/草稿差异、引擎与格式支持边界，不附开发过程日志。
